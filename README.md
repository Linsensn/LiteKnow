# 🎓 LiteKnow 教育助手 AI Agent

LiteKnow 是一款专为 K12 教育阶段打造的轻量化 AI 辅助学习微信小程序。在“双减”政策背景下，致力于为学生和教师提供高效、精准、即开即用的一站式智能学习解决方案。

本项目基于 **LangChain** 框架构建智能体（Agent），底层接入 **DeepSeek** 大语言模型，通过“规划—执行—校验”的全流程控制，实现真正的智能化辅助教学。

---

## ✨ 核心功能模块

LiteKnow 的核心交互围绕四大高频学习场景展开：

*   **📝 课文摘要**：自动提炼课文核心主旨与段落大意。支持图片上传与 OCR 识别，学生可直接拍照提取课本文字进行分析。
*   **💡 知识精讲**：针对薄弱知识点，提供 AI 深度剖析与通俗易懂的讲解，支持多轮对话追问。
*   **🎯 智能测验**：基于当前学习的课文或知识点，AI 自动生成专属习题（包含单选、多选等），支持在线自测与实时难度评估。
*   **📁 错题本与学习档案**：系统自动记录历史会话，提供以题回扣知识点的关联查询，支持错题与重难点一键收藏，打造个性化学习闭环。

---

## 🛠️ 技术栈架构

本项目采用标准的前后端分离架构设计：

### 📱 前端 (WeChat Mini Program)
*   **开发框架**：微信小程序原生开发 (JS + WXML + WXSS)
*   **UI 架构**：模块化设计，包含独立工作台与个人中心，支持微信无感授权登录。
*   **核心能力**：原生相册/相机 API 接入、流式 Markdown 数据渲染预留。

### ⚙️ 后端 (Python - 规划中)
*   **核心框架**：FastAPI 高性能异步接口服务。
*   **AI 引擎**：LangChain Agent 架构 + DeepSeek LLM。
*   **核心组件**：TaskParser (任务拆解与调度)、多工具链集成 (摘要工具、出题工具等)。

## 📂 前端目录结构说明

```text
FRONTEND/
├── app.js                      # 全局逻辑入口：管理登录状态与全局数据
├── app.json                    # 全局路由与 TabBar 底部导航配置
├── pages/                      # 核心页面目录
│   ├── index/                  # 【工作台】核心功能卡片与快捷入口
│   ├── user/                   # 【我的】个人信息编辑、错题本与历史记录
│   ├── summary/                # 【课文摘要】功能交互页
│   ├── explain/                # 【知识精讲】功能交互页
│   ├── quiz/                   # 【智能测验】功能交互页
│   └── mistakes/               # 【错题本】功能交互页
└── utils/                      # 全局公共工具函数 (如网络请求封装)
```

## 📂 后端目录结构说明
```text
backend/              # 后端服务层：基于 FastAPI 框架构建的核心接口服务。
├── app/              # 应用主入口：负责生命周期管理、中间件挂载及全局异常拦截。
├── routers/          # 路由控制层：定义 HTTP API 端点，接收前端请求并进行路由分发。
├── services/         # 业务逻辑层：承上启下，编排核心业务规则，调度数据层或 AI 层。
├── crud/             # 数据访问层：封装所有与底层数据库交互的增删改查操作。
├── models/           # 数据模型层：定义 ORM 实体数据类，映射底层数据库表结构。
├── schemas/          # 数据契约层：定义 Pydantic 模型，负责前后端出入参校验与序列化。
├── agent/            # AI 引擎层：独立封装大模型交互、任务拆解与 Agent 工具链调用。
├── config/           # 全局配置中心：集中管理环境变量、数据库连接池及 API 密钥。
└── utils/            # 通用工具层：存放跨模块复用的公共方法，如依赖注入、鉴权工具等。
```
