# LiteKnow 质控 (QC) 本地验收流程规范

作为质量控制环节，验收测试的核心是保证环境的隔离性与测试的真实性。在验收组员提交的 Pull Request (PR) 时，请严格执行以下标准化步骤。

> **⚠️ 环境特殊说明**：
> 1. **无云端共享库**：所有人的本地 MQL 数据库相互独立。
> 2. **依赖迁移脚本**：拉取被测分支后，必须通过 Alembic 同步本地数据库结构。
> 3. **微信小程序前端**：前端验收必须使用**微信开发者工具**进行实机或模拟器调试。

---

#### 第一步：获取被测分支代码

在本地终端中，拉取远端更新并切换到组员提交的开发分支（以实际的 PR 分支名为准）：
```bash
git fetch
git checkout 被测分支名
```

#### 第二步：启动验证环境与同步数据库

1. **拉起全栈容器**：
   在项目根目录执行以下命令，系统将根据当前测试分支的代码自动构建并启动后端、MySQL 和 Redis 等服务。
   ```bash
   docker-compose -f docker-compose.dev.yml up -d
   ```

2. **⚠️ 强制步骤：同步本地数据库结构**：
   由于团队**没有共享云端数据库**，当开发人员在分支中新增了数据表或修改了字段时，拉取代码后，你的本地 MySQL 中并没有这些变更。**必须**手动执行数据库迁移命令，将代码中的 Model 变更应用到你的本地 MySQL 容器中：
   ```bash
   # 务必执行此命令，使本地 MySQL 结构与代码保持同步
   docker exec -it liteknow-backend-dev alembic upgrade head
   ```
   > **质控决断**：如果执行上述命令报错（如提示 `No such table` 或无法生成迁移），说明开发人员遗漏了将 `migrations/versions/*.py` 迁移文件提交到 Git 仓库。此时应直接打回 PR，无需继续测试。

#### 第三步：执行真机/模拟器联调验证

容器启动且数据库同步完成后，依次进行以下维度的验证：

* **后端接口测试 (Apifox)**：
  打开 Apifox，将运行环境切换为“本地环境 (`http://localhost:8000/api/v1`)”，运行该 PR 涉及的接口用例。检查返回状态码是否为 `200`，且数据结构是否完全契合契约设计。

* **微信小程序前端测试**：
  打开 **微信开发者工具**，导入本项目的小程序前端代码目录。在工具右上角“详情” -> “本地设置”中，**勾选“不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书”**。此时即可在微信开发者工具中模拟用户真实交互链路，验证微信小程序功能是否按预期工作（注意小程序接口应指向 `http://localhost:8000`）。

* **服务端健康度检查**：
  在终端执行以下命令，查阅后端日志中是否存在隐蔽的 500 错误或异常抛出：
  ```bash
  docker logs --tail 100 liteknow-backend-dev
  ```

* **代码规范审查**：
  在 VS Code 中审查该分支新增的 `.py` 或 `.wxml/.js` 文件。检查是否包含强制要求的版权声明注释头，核心函数是否具备标准注释。

#### 第四步：返回 PR 盖章确认

完成本地物理验证与代码审查后，返回 GitHub 对应的 PR 页面进行决策。

* **测试通过 (Approve)**：
  若功能符合预期且无异常日志，点击“Approve”并执行“合并 (Merge)”，将该分支正式合入 `develop`（或 `dev`）主干。
* **测试驳回 (Request Changes)**：
  若发现任何 Bug（包括接口契约不一致、小程序页面报错、控制台异常日志等），**禁止质控人员自行修改代码**。请在 PR 的评论区详细记录复现步骤或报错日志，并点击“Request Changes”，将其打回给原开发人员。

#### 第五步：打扫本地战场

验收流程结束后，必须清理本地临时环境，避免干扰后续其他 Issue 的测试。

1. 停止并移除本次测试拉起的容器环境：
   ```bash
   docker-compose -f docker-compose.dev.yml down
   ```
2. 切换回主干分支，并强制删除已测试完毕的本地临时分支：
   ```bash
   git checkout develop
   git branch -D 待测试任务分支名
   ```
